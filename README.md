# Myanmar OCR (မြန်မာစာ စကင်ဖတ်)

ဓာတ်ပုံမှ မြန်မာစာကို ဖတ်ပေးတဲ့ single-file web app (`index.html`)။

- Gemini (API key ထည့်ရန်) သို့မဟုတ် offline Tesseract engine
- ပုံကို ဖြောင့်/ကြည်အောင်ပြင်၊ အပိုင်းခွဲ ချဲ့ဖတ်
- မူရင်းပုံစံအတိုင်း (table, ပုံ, အရောင်) A4 ပုံပြန်ထုတ်
- Translate / restyle / Q&A

Netlify, GitHub Pages စတဲ့ website မှာတင်ပြီး Safari/Chrome ကနေ ဖွင့်ပါ။
